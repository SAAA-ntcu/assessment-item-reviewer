# Formal Report Editorial Style Guide

## Purpose

Use this guide for author-created formal report prose, captions, explanatory tables, headings, and reviewer-facing narrative. It supplements the general Language & Semantic QA. It does not replace subject-content review.

## Source hierarchy

1. Preserve the exact wording of authoritative source quotations and clearly marked verbatim excerpts.
2. For author-created report prose, use the bundled official unified-wording table as a preferred wording baseline when the rule is clear and low-risk.
3. Use the bundled revised punctuation handbook as the punctuation baseline.
4. If the manuscript or organization has an explicit local style rule that conflicts with these editorial baselines, follow the explicit local rule and note the difference only if it matters.

## Three-way decision rule

- Clear preferred form: correct directly. Example preferred form from the official table: `部分`; the variant `部份` should be standardized in formal report prose.
- Context-dependent pair: decide by meaning or part of speech before correcting. Do not use blind find/replace.
- Officially allowed punctuation alternatives: do not label either alternative wrong. Raise a consistency comment only when mixed forms reduce report professionalism or readability.

## Scope boundaries

Do not mechanically normalize:

- verbatim quoted source text;
- an actual assessment item reproduced as source evidence, unless the item itself is under editorial review or the issue affects validity/clarity;
- formulas, statistical notation, code, URLs, file paths, identifiers, or English passages;
- discipline-specific symbols that intentionally follow another convention.

When an actual item contains a wording/punctuation problem that materially affects interpretation, review it as an item-quality issue rather than silently treating it as ordinary report copyediting.

## Repetition and Word comments

For a repeated mechanical pattern, normally add one representative whole-document comment rather than a comment on every occurrence. Use a concise consistency note and identify the preferred form.

If the same location also contains a substantive assessment, curriculum, data, or semantic problem, keep the substantive issue separate from the mechanical style correction.
