# Report-pattern reference

The supplied Grade 3 analysis report uses a recurring item-analysis structure that this skill should recognize:

1. learning content / learning point;
2. knowledge dimension and cognitive dimension;
3. item image/text;
4. response rates, pass rate, high-group rate, low-group rate, discrimination;
5. assessment objective;
6. data description;
7. option and student-performance explanation;
8. prerequisite / target / extension learning content;
9. teaching recommendations, often split into possible error causes and core concept/teaching focus.

The report defines high group as the top 27 percent of valid total scores and low group as the bottom 27 percent. Discrimination is high-group item pass rate minus low-group item pass rate.

When a user provides only part of this structure, review what is present and do not invent missing statistics or missing item details.
