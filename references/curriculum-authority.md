# Curriculum authority and source roles

## Source hierarchy

Keep source roles separate and use the strongest available source for each kind of claim.

1. Formal curriculum guideline: primary authority for official wording, learning stage, learning performance/content, curriculum codes, and formal curriculum placement.
2. Official curriculum handbook or explanatory manual: secondary/interpretive source. Use it to clarify meaning, progression, examples, teaching/assessment interpretation, or implementation context. Do not let it override the formal curriculum.
3. Actual assessment item: primary evidence for what the student is actually asked to do.
4. Supplied data/statistics: primary evidence for report-level performance claims.
5. Manuscript text: object under review.

Do not silently reconcile conflicts among sources. Flag the mismatch or state that the source roles differ.

## Subject depth

Follow `subject-routing.md`.

### Mathematics

Detailed curriculum alignment is enabled by default when the report contains curriculum claims/codes. Use the bundled official grade reference as primary authority and the bundled mathematics curriculum handbook as secondary interpretation.

### Science, English, Chinese

Default to general assessment-and-readability review, not a specialist curriculum audit.

However, when the manuscript explicitly cites a curriculum code, learning performance/content, learning stage, formal curriculum claim, or grade/stage statement, perform a targeted verification against the bundled official curriculum PDF. Use the corresponding handbook-orientation note only to clarify scope or progression when needed.

Do not turn the presence of a curriculum source into a requirement to audit every item code unless the user explicitly requests that depth.

### Other subjects

Default to general review. Perform curriculum verification only when the user supplies the relevant authoritative source or the manuscript contains a concrete claim that can be verified from available evidence.

## Evidence discipline

- Do not replace source-derived claims with general model knowledge.
- Do not invent curriculum codes, stage boundaries, or official wording.
- Do not infer「符合課綱」solely because a topic sounds age-appropriate.
- Do not declare「超綱」solely from model memory.
- When a handbook example differs from a formal curriculum statement, the formal curriculum governs.
- Preserve the terminology and structure of the supplied official source when commenting on curriculum alignment.
- If the source does not settle a specialist issue, state the uncertainty and recommend subject-expert verification.
