# Cross-subject review rubric

Use this rubric after independently inspecting the actual item.

## 1. Assessment objective

Check whether the paragraph answers: What does this item actually assess?

Review for:

- response format mistaken for assessment purpose;
- mismatch between stated objective and actual item demand;
- construct too narrow or too broad;
- unnecessary specification of one preferred method/strategy;
- student-performance interpretation placed inside the objective;
- teaching advice placed inside the objective;
- unsupported claims about familiarity, difficulty, prevalence, or typical behavior.

## 2. Item, answer, and option consistency

Verify what can be verified from the supplied source:

- correct answer/option when determinable;
- item text vs. figure/table/audio transcript/reference material;
- option labels and descriptions;
- numbers, percentages, units, names, categories, conditions, and examples;
- copied wording or data that conflict across sections;
- report explanation vs. actual task demand.

For subject-specialist disputes that cannot be established from supplied authoritative evidence, do not guess.

## 3. Option/distractor analysis

Check whether each explanation is actually supported by the option and item structure.

Distinguish different plausible response processes instead of assigning the same generic explanation to all wrong options when the options imply different paths.

Use uncertainty language when a response process is inferred rather than observed.

Do not require a standalone mastery/deficit scan. If a claim is logically stronger than the evidence supports, handle it under general assessment logic/evidence strength.

## 4. Statistical interpretation

When statistics are present, verify:

- values in tables vs. prose;
- pass/accuracy rates vs. narrative claims;
- high/low-group values and discrimination when the report defines them;
- subgroup labels and denominators;
- increase/decrease/easier/harder claims against actual numbers;
- consistent terminology across the report.

Do not invent psychometric cutoffs or significance claims.

## 5. Teaching recommendations

Check whether the teaching response follows from the analysis.

Prefer:

item evidence -> plausible interpretation -> teaching issue -> targeted teaching action

Review for:

- direct alignment with the diagnosed issue;
- examples/activities that actually address the item difficulty;
- excessive background that hides the immediate teaching action;
- terminology and level usable by the target-grade subject teacher;
- unsupported specialist claims presented as certainty.

## 6. Curriculum alignment

Apply the depth specified in `subject-routing.md`.

For mathematics, use detailed bundled curriculum/handbook references when relevant.

For science, English, and Chinese, default to general review and use the bundled official curriculum PDF only for targeted verification of concrete curriculum claims; use the matching handbook-orientation note as secondary interpretation. For other subjects, perform targeted checks only when an authoritative source is available.

## 7. Reader fit

Assume the main reader is the teacher of the target grade and subject unless the user says otherwise.

Check whether the report lets that teacher quickly determine:

1. What is the item asking students to do?
2. How is the report interpreting the response data/options?
3. Does that interpretation make sense from the item/data?
4. What teaching action is being suggested?
5. Can the teacher understand the reasoning without reconstructing missing links?

Frame substantive comments around the reader problem, then the cause, then the revision direction.

## 8. General language and editorial QA

Run `language-editorial-qa.md` after substantive review.

Check spelling, missing/repeated text, punctuation, encoding, terminology, cross-references, sentence meaning, paragraph coherence, professional wording, and formatting consistency.
