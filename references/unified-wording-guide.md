# Unified Wording Guide

## Use

Apply this guide to author-created formal assessment-report prose. The bundled official unified-wording table is the source baseline. Use it conservatively for clear, report-relevant wording choices; do not import the entire legal drafting register into educational prose.

## Automatic vs. advisory use

- The curated rows below are low-risk formal-report conventions and may be applied directly when the context matches.
- Rows that appear only in the full legal table but are not curated below are advisory, not automatic corrections. Consult the source and the report's own style before using them.
- For a noun/verb or meaning-dependent distinction, determine grammatical/semantic function before correcting.
- Do not normalize proper nouns, direct quotations, historical text, or reproduced item/source text solely for house style.
- Do not infer a new rule merely because an unlisted word contains the same character.
- For repeated variants, prefer one representative whole-document consistency comment when practical.

## Reviewer behavior

- Clear fixed preference: direct correction.
- Context-dependent distinction: explain the grammatical or semantic reason briefly.
- If uncertainty remains, ask for intent rather than inventing a house rule.
