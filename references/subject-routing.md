# Subject routing policy

Use this file before applying subject-specific review depth.

## Core rule

Use one common assessment-report review framework across subjects, but vary the depth of curriculum and subject-matter adjudication.

The Skill's main role is assessment logic + teacher readability + report consistency. It is not a substitute for a subject specialist.

## Mathematics

Default mode: general review + detailed curriculum alignment.

Use the target-grade official mathematics curriculum excerpt and matching mathematics curriculum handbook when the report contains learning-content codes, curriculum claims, prerequisite/follow-up claims, or grade-boundary statements.

Check mathematical correctness directly when the item provides enough evidence.

## Science

Default mode: general review.

Review item/report consistency, assessment-objective logic, option/distractor explanation, response statistics, teaching linkage, teacher readability, document coherence, and language quality.

Do not automatically perform an exhaustive science curriculum-code or content-boundary audit.

If the manuscript explicitly cites a science learning-performance/content code, learning stage, or formal curriculum claim, verify that concrete claim against `curriculum-science-2018.pdf`. Use `science-curriculum-orientation.md` to navigate the structure and `science-handbook-orientation.md` as secondary interpretation when stage progression, inquiry, or assessment meaning matters.

Do not require every selected-response item to assess full inquiry performance merely because the science curriculum values inquiry.

If a claim requires specialist physics, chemistry, biology, or earth-science judgment beyond the supplied sources, mark it for subject-expert verification.

## English

Default mode: general review.

Review item/report consistency, assessment-objective logic, option/distractor explanation, response statistics, teaching linkage, target-grade teacher readability, document coherence, and language quality.

Do not automatically perform an exhaustive English curriculum-code or content-boundary audit.

If the manuscript explicitly cites an English learning-performance/content code, learning stage, or formal curriculum claim, verify that concrete claim against `curriculum-english-2018.pdf`. Use `english-curriculum-orientation.md` to navigate the structure and `english-handbook-orientation.md` as secondary interpretation.

Remember that some learning performances recur across stages with different difficulty/complexity. Do not treat recurrence as proof that the same surface task is equally appropriate at every stage.

If a claim requires specialist linguistic/pragmatic judgment beyond the supplied sources, mark it for subject-expert verification.

## Chinese / Mandarin

Default mode: general review.

Review assessment logic, item/report consistency, option/distractor reasoning, data interpretation, teaching linkage, teacher readability, coherence, terminology consistency, and language/editorial quality.

Do not automatically perform an exhaustive Chinese curriculum-code or content-boundary audit.

If the manuscript explicitly cites a Chinese learning-performance/content code, learning stage, or formal curriculum claim, verify that concrete claim against `curriculum-chinese-2018.pdf`. Use `chinese-curriculum-orientation.md` to navigate the structure and `chinese-handbook-orientation.md` as secondary interpretation.

Do not force learning performance and learning content into a one-to-one relationship; the official handbook allows multiple correspondence patterns.

If a claim requires specialist literary, linguistic, or curriculum judgment beyond the supplied sources, mark it for subject-expert verification.

## Other subjects

Default mode: general review.

Apply the common rubric and only perform curriculum checks when the user supplies the relevant authoritative source or the manuscript contains a concrete curriculum claim that can be verified from available evidence.

## Important boundary

Do not convert「general review」into「no content check」.

Still flag:

- obvious contradictions between item and report;
- clearly wrong answer/option descriptions;
- obvious factual or terminology errors directly verifiable from supplied material;
- unsupported statistical conclusions;
- broken logic between analysis and teaching recommendation;
- teacher-facing wording that is unclear or misleading.

When evidence is insufficient for a subject-specialist conclusion, say so instead of guessing.
