# Cross-subject review comment examples

Use these as style examples, not reusable diagnoses.

## Assessment objective mismatch

為利教師理解本題真正的評量重點，建議再確認評量目標與實際題目的一致性。目前文字主要描述「選出正確答案」的作答形式，尚未清楚說明學生需要理解或判斷的內容。建議改以本題實際需要的概念或資訊處理歷程表述。

## Option analysis lacks differentiation

目前數個誘答皆以相同原因概括，但各選項在題目資訊的使用方式並不相同，教師較難從分析中看出不同錯答可能代表的作答歷程。建議依各選項實際特徵分別說明；若無法由選項唯一判定學生歷程，改用「可能」等保留語氣。

## Data conclusion does not follow

表格數值與本段結論之間的連結尚不清楚，讀者無法直接由所列數據驗證目前的比較敘述。建議先確認比較基準與數值，再依實際差異重寫結論，避免加入資料未支持的因果或趨勢判斷。

## Teaching recommendation disconnected

目前教學建議提供的是較廣泛的主題教學內容，但與前述試題分析指出的具體困難連結較弱。建議先補上直接回應本題錯誤或理解困難的教學處理，再將其他背景或延伸內容另列，讓教師較容易看出「分析結果—教學行動」的關係。

## Teacher readability / coherence

本段先後使用兩個不同名稱指涉同一概念，但未說明兩者關係，教師閱讀時容易以為是不同項目。建議統一用語，或首次轉換時補充說明，以維持整章的一致性。

## Specialist boundary

此處涉及較細的學科內容判定，現有試題與報告文字不足以支持明確結論。建議先保留現有敘述並註記「需由學科專家確認」，不要僅依一般常識直接改寫。
