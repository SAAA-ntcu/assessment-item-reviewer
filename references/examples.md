## Example 1 (source comment 5)

建議重新釐清本段的論證關係。「因……但是……」在語意上較不連貫，且「高、低分組學生答對率應相距不遠」屬於預期性判斷，建議補充其理論或分析依據；若無明確依據，可改為直接描述高、低分組答對率的實際差異，以避免產生論證跳躍。

## Example 2 (source comment 6)

1.為利讀者快速掌握本題的評量重點，建議將「作答形式」與「評量目的」分開敘述。目前「要求學生選出正確的答案」較屬於作答方式，若與評量能力放在同一句中，容易使讀者不易掌握本題真正欲評量的核心。2.建議直接說明本題透過「含有多餘資訊的連乘兩步驟情境」，評量學生辨識與問題相關的資訊，並完成連乘兩步驟解題的能力。如此可使讀者在閱讀本題說明時，較快掌握「題目特徵」與「評量重點」之間的關係3. 為使讀者較容易理解本題的題型特徵，建議補充說明「多餘資訊」的意義。目前段落已說明一步驟、兩步驟與三步驟問題的差異，但對本題另一項重要特徵「多餘資訊」尚未進一步說明，容易使讀者知道本題是兩步驟問題，卻不一定清楚「多餘資訊」在題目中的作用。4.建議簡要說明多餘資訊係指「題目中雖有提供，但解決問題時不需使用的資訊」，學生需依據問題所求判斷哪些條件需要使用。另可適度調整段落順序，先說明「兩步驟問題」與「多餘資訊」的概念，再回到本題的評量內容，使讀者能依序理解「概念定義 → 本題特徵 → 評量能力」，閱讀脈絡會更清楚

## Example 3 (source comment 7)

## Example 4 (source comment 8)

## Example 5 (source comment 10)

1.為使讀者能清楚理解試題分析與後續教學處理之間的關係，建議教學建議直接對應前述不同錯誤類型。目前教學建議(1)主要透過分解兩個運算步驟，協助學生建立連乘兩步驟的解題歷程，較能回應只完成第一步的學生。2.但本題亦涉及「多餘資訊」的辨識，現有教學建議對於如何協助學生判斷哪些資訊與問題所求有關、哪些資訊不需使用，著墨較少。建議增加相關的資訊辨識與題意理解活動，使教學策略能同時回應「步驟未完成」及「誤用多餘資訊」兩類主要困難。3.另外，教學建議(2)、(3)若主要是在說明課程範圍、數學性質或其他數量關係，可考慮另列為「教學提醒」或「延伸說明」，使讀者更容易區分本題直接的補救教學策略與其他相關課程知識。

## Example 6 (source comment 11)

1.為利讀者理解學生「錯在哪一個環節」，建議進一步區辨各誘答選項所反映的不同解題歷程，而不宜均概括為「不具備三位數乘以一位數直式計算能力」。2.選擇①、②的學生可能主要將十位的乘法視為獨立運算，未將個位計算產生的進位納入考量；選擇③的學生則已注意到個位的進位，但只檢查十位結果，尚未繼續利用十位產生的進位及百位結果進行整體檢核。建議依此呈現不同層次的理解情形，以增加試題分析的診斷性。3.另第(4)的數學敘述建議再確認。「4－2＝2，所以積的十位數字是2」容易造成誤解，因為積的十位數實際仍為4；此處較精確的意思應是：扣除個位進位的2之後，未知十位數乘以4的結果，其個位數須為2，因此3與8皆可能符合十位條件，尚須再利用百位結果及進位關係判斷正確答案。建議將此推理過程說明完整。4.另外，「答對率52%，顯示超過五成學生已具備……能力」的推論較強，建議改為描述學生「在本題缺數直式情境中的表現」，避免由單一試題直接推論學生已完整具備該項能力。

## Example 14 (source comment 20)

## Example 16 (source comment 22)

1.為使教學建議能直接回應本題的作答困難，建議將重點聚焦於「分數必須連同所指涉的整體與單位一起理解」。目前部分內容延伸至分數命名、單位分數大小比較及不同年級的比率概念，資訊較多，但與本題主要錯誤來源的連結不夠直接。2.建議優先透過相同分數、不同整體的具體比較活動，引導學生理解，例如「1條繩子的5/6」與「1公尺的5/6」是否相同，必須先知道1條繩子與1公尺的長度關係，不能只看到兩個5/6就判斷一樣大。如此可直接回應選擇①學生可能只注意分數數字、忽略基準量的問題。3.另外，若教學建議(3)主要欲處理「分數是帶單位的量」或「分數所指涉的整體」，建議以三年級教師容易操作的具體表徵說明，避免過度延伸至「比率」等後續概念，以降低閱讀負荷。4.建議檢查教學建議與前述課綱說明的用語一致性。前文已指出三年級分數教學「只用分數一詞，不出現真分數與假分數的名詞」，但教學建議(1)又寫「幫助學生在具體情境中理解真分數的意義」，容易使讀者產生疑惑。若此處是教師端的數學內容說明，建議交代清楚；若是提供教師直接使用的三年級教學語言，則建議避免使用「真分數」一詞。5.另教學建議(2)所稱「被分割的對象必須密度均勻」建議再確認表述是否精確。分數教學的核心通常在於整體的確定與等分，而「蘋果顏色不同」、「披薩配料不同」較接近視覺特徵或內容物分布可能干擾學生判斷，未必宜直接概括為「密度不均勻」。建議改由「選擇容易明確等分、且不易受其他外觀特徵干擾的素材」來說明，較不易造成概念誤解。

1.建議特別增加「32在第一次移動中是終點，在第二次移動中又成為起點」的說明，幫助教師協助學生辨識同一位置在不同移動歷程中的角色。2.教學建議(2)以直尺說明「刻度所代表的位置」與「兩刻度間的距離」，亦能直接回應本題學生可能混淆位置與距離的問題，建議可與第(1)點連結說明。3.教學建議(3)關於省略部分刻度，以及第(4)點如何繪製數線，較偏向數線概念建立或後續延伸內容，與本題主要錯誤反應的直接關聯較低。若有保留必要，建議另列為延伸教學，以避免分散本題的教學焦點。
