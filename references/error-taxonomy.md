# General error and review taxonomy

Use these as diagnostic prompts, not mandatory labels.

## Assessment-objective issues

- response-format/construct confusion
- objective does not match actual item demand
- construct too narrow
- construct too broad
- preferred strategy mistaken for assessed construct
- performance interpretation placed inside objective
- teaching action placed inside objective
- unsupported difficulty/familiarity/prevalence claim

## Item and option-analysis issues

- answer/option mismatch
- item image/text/table mismatch
- copied number/name/label error
- option explanation does not match the option
- same generic explanation applied to materially different distractors
- inferred response process stated as observed fact
- condition or information in the item ignored by the manuscript
- partial-step or incomplete-process possibility overlooked
- irrelevant information or role confusion overlooked
- terminology or referent shifts across sections

## Statistical/report-logic issues

- prose value differs from table value
- denominator/group label inconsistency
- discrimination/pass-rate wording inconsistent
- trend claim does not match the numbers
- causal claim drawn from descriptive data without support
- comparison objects are not comparable
- conclusion does not follow from preceding evidence

## Teaching-recommendation issues

- recommendation does not respond to diagnosed issue
- broad topic teaching substitutes for targeted response
- first activity/example has a different structure from the diagnosed difficulty
- background or curriculum history overwhelms immediate teaching action
- recommendation repeats analysis without giving a usable action
- specialist claim presented without authoritative support

## Curriculum/source issues

- cited curriculum code/text does not match supplied official source
- learning stage/grade claim conflicts with supplied official source
- secondary manual treated as stronger than formal curriculum
- manuscript states "符合課綱" or "超綱" without a verifiable basis
- subject-specific curriculum logic imported from another subject

## Reader and language issues

- unclear antecedent/referent
- broken modifier attachment
- missing connective or comparison basis
- unsupported connector such as therefore/however
- paragraph focus drifts
- repeated background creates unnecessary reading load
- terminology changes without explanation
- residual drafting note
- encoding/symbol corruption
- isolated typo/format inconsistency

## Severity by consequence

Escalate a seemingly minor wording error when it changes answer validity, item roles, evidence, statistical interpretation, curriculum interpretation, or teaching conclusion.
